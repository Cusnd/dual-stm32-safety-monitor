# LM393 比较器

[硬件索引](../index.zh-CN.md) | [English](lm393.en.md)

## 项目角色

LM393 是气体、火焰、雨量、热敏等模块常用的双比较器，用来把模拟阈值转换为数字 `DO` 信号。

## DIP/SOIC-8 引脚

| 引脚 | 名称 | 功能 |
|---|---|---|
| 1 | `OUT1` | 比较器 1 开集输出 |
| 2 | `IN1-` | 比较器 1 反相输入 |
| 3 | `IN1+` | 比较器 1 同相输入 |
| 4 | `GND` | 地 |
| 5 | `IN2+` | 比较器 2 同相输入 |
| 6 | `IN2-` | 比较器 2 反相输入 |
| 7 | `OUT2` | 比较器 2 开集输出 |
| 8 | `VCC` | 电源 |

## 电气注意事项

- 输出为开集，需要上拉电阻。
- 常见模块用电位器设置阈值。
- 输出极性取决于传感器电压接到同相端还是反相端。

## 比较器接口

- 输入端把传感器模拟节点与电位器阈值比较。
- 数字输出上拉后可直接给 GPIO 读取；它不是总线协议，没有时钟。
- 参考固件把火焰 `DO` 和热敏 `DO` 都按低电平触发处理。

## 通用参考电路

```text
Sensor AO -> IN+
电位器阈值 -> IN-
OUT -> 上拉 -> 模块 DO
DO -> STM32 GPIO 输入
```

## 项目使用

- 热敏 DO 接板 A `PB9`。
- 火焰 DO 接板 A `PB13`。
- MQ 和雨量比较器输出不是参考固件必需信号，除非具体模块另行说明。

## 调试要点

- DO 悬空时检查上拉。
- DO 极性不符合预期时，用万用表分别测未触发/触发状态，或查看模块实际原理图。
