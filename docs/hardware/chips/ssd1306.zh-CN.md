# SSD1306 OLED 控制器

[硬件索引](../index.zh-CN.md) | [English](ssd1306.en.md)

## 项目角色

SSD1306 驱动板 B 的 128x64 单色 OLED 模块。参考固件使用软件 I2C 风格写入。

## 相关控制器信号

| 信号 | 功能 | 模块层说明 |
|---|---|---|
| `VDD`、`VSS` | 逻辑电源和地 | 通常在模块内部处理 |
| `VCC` | OLED 面板驱动电源 | 模块可能内部升压产生 |
| `SCL/D0` | 串行时钟 | 模块对外标为 `SCL` |
| `SDA/D1` | 串行数据 | 模块对外标为 `SDA` |
| `RES#` | 复位 | 常由模块 RC/复位电路处理 |
| `SA0/D/C#` | I2C 地址选择或数据/命令 | I2C 模块上通常固定 |
| `SEGx/COMx` | OLED 段/公共驱动 | 面板内部连接 |

## 电气能力与接口

- 0.96 寸模块常见为 128x64 显存。
- 控制器支持 I2C、SPI、并口等模式，取决于模块跳线/封装。
- 常见 I2C 7 位地址为 `0x3C`。

## 通用参考电路

```text
3V3 -> OLED VCC
GND -> OLED GND
PB6 开漏 -> SCL，并上拉
PB7 开漏 -> SDA，并上拉
```

## 固件映射

- `OLED_Init_Custom()` 发送 SSD1306 初始化序列。
- `OLED_PrintLine()` 把 5x7 字体写入 128 像素页。
- 当前没有 ACK 错误处理；模块未接时表现为屏幕不显示。

## 移植要点

- 如果模块地址是 `0x3D`，需要改 OLED 地址常量。
- 如果模块是 SPI-only，需要新增传输层，不能直接沿用当前驱动。
