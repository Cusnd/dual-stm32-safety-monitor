# WS2813E 可寻址 RGB LED（Legacy 参考）

[硬件索引](../index.zh-CN.md) | [English](ws2813e.en.md)

## 当前状态

本页保留为旧演示和未来扩展的硬件参考。当前 CMake 构建不编译 WS2813 驱动，MONITOR 固件也不会驱动 `PA6/TIM3_CH1`。

## 信号

不同供应商封装/模块命名可能不同。典型模块通常包含以下信号。

| 信号 | 功能 | 旧参考连接 |
|---|---|---|
| `VDD/VCC` | 灯珠电源 | 5 V |
| `GND/VSS` | 地 | 与板 B 共地 |
| `DIN` | 数据输入 | 若恢复固件支持，可通过电平转换接 `PA6 / TIM3_CH1` |
| `DOUT` | 数据输出 | 接下一颗灯 DIN，单颗时不用 |
| 备份输入/输出 | WS2813 系列冗余数据通道 | 按具体模块 datasheet 连接 |

## 电气要点

- 单线自时钟 RGB 协议，约 800 kHz。
- 很多实现使用 GRB 字节顺序。
- 灯珠电源为 5 V，而 STM32 数据电平为 3.3 V，建议加入电平转换。
- 需要按灯珠数量和亮度预算 5 V 电源。

## 重新启用检查表

1. 在 `App/Drivers/` 中恢复或重新实现 WS2813 驱动。
2. 把驱动源文件加入 `CMakeLists.txt` 的 `APP_MONITOR_SOURCES`。
3. 明确处理 `PA6` 与 SENSOR 雨量输入之间的角色复用关系。
4. 如果该功能重新成为现役功能，同步更新 `WIRING.md`、README、模块参考、JSON schema 和测试。
