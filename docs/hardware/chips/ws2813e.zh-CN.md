# WS2813E 可寻址 RGB LED

[硬件索引](../index.zh-CN.md) | [English](ws2813e.en.md)

## 项目角色

WS2813E 是板 B 外置高可视状态 RGB。参考固件用 TIM3 PWM + DMA 驱动 1 颗灯。

## 信号

不同供应商封装/模块命名可能不同。参考设计至少需要以下信号。

| 信号 | 功能 | 参考连接 |
|---|---|---|
| `VDD/VCC` | 灯珠电源 | 5 V |
| `GND/VSS` | 地 | 与板 B 共地 |
| `DIN` | 数据输入 | `PA6 / TIM3_CH1`，建议加电平转换 |
| `DOUT` | 数据输出 | 接下一颗灯 DIN，单颗时不用 |
| 备份输入/输出 | WS2813 系列冗余数据通道 | 按具体模块 datasheet 连接 |

## 电气能力与接口

- 单线自时钟 RGB 协议，约 800 kHz。
- 参考固件按 GRB 字节顺序发送。
- 灯珠电源是 5 V，MCU 数据电平是 3.3 V。

## 通用参考电路

```text
5V -> VDD
GND -> GND，并与板 B 共地
PA6/TIM3_CH1 -> 电平转换 -> DIN
DOUT -> 下一颗灯 DIN，用灯带时连接
```

## 固件映射

- `WS2813_LED_COUNT` 默认 `1`。
- `WS2813_FillBuffer()` 按 GRB 顺序填充。
- `Monitor_UpdateAlarm()` 把 normal/warn/danger/node-lost 映射为绿/琥珀/红/蓝。

## 调试要点

- 颜色错位时，检查 GRB 顺序和模块型号。
- 闪烁时，缩短 DIN 线、改善共地、增加电平转换。
- 使用多颗灯时，同步修改 `WS2813_LED_COUNT` 和电源预算。
