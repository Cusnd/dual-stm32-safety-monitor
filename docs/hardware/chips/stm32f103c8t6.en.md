# STM32F103C8T6 MCU

[Hardware index](../index.en.md) | [中文](stm32f103c8t6.zh-CN.md)

## Role

STM32F103C8T6 is the MCU on both nodes. Board A samples sensors and sends USART3 frames. Board B receives frames, drives display/alarm outputs, logs to W25Q64, and emits JSON Lines.

## Package And Electrical Capability

| Item | Reference value |
|---|---|
| Core | ARM Cortex-M3 |
| Max clock | 72 MHz |
| Flash / SRAM | 64 KB / 20 KB for C8 density |
| Package used by reference design | LQFP48 |
| Supply | 2.0-3.6 V digital supply; ADC uses VDDA |
| ADC | 12-bit ADC, 0 to VDDA input range |
| Debug | SWD on `PA13/PA14` |

## Peripheral Interfaces And Timing

- USART1 and USART3 use `115200 8N1`; USART3 is the board-to-board binary frame link.
- Board A ADC channels are `ADC1_CH4/5/6/7`; all analog inputs must stay within 0..VDDA.
- Board B SPI2 talks to W25Q64 on `PB12/PB13/PB14/PB15`; `PB12` is controlled as GPIO chip select.
- Board B TIM3_CH1 on `PA6` generates the WS2813E 800 kHz waveform through DMA.
- OLED I2C is bit-banged on `PB6/PB7` as open-drain GPIO rather than using the hardware I2C block.

## Generic Reference Circuit

```text
3V3 rail -> VDD/VDDA with local 100 nF decoupling
GND rail -> VSS/VSSA
8 MHz HSE -> OSC_IN/OSC_OUT, if the target board provides it
BOOT0 -> pull-down for normal flash boot
NRST -> pull-up plus reset switch if present
PA13/PA14 -> SWD header
```

## Firmware Mapping

- `SystemClock_Config()` configures 8 MHz HSE to 72 MHz SYSCLK.
- `ADC1_Init_Custom()` samples `PA4/PA5/PA6/PA7` on the SENSOR image.
- `Node_USART3_Init()` uses `PB10/PB11` on both images.
- `WS2813_Init_Custom()` uses TIM3_CH1 on `PA6` only on the MONITOR image.
- `Flash_Init_Custom()` uses SPI2 on `PB12/PB13/PB14/PB15` only on the MONITOR image.

## Porting Checks

- If the target board lacks an 8 MHz HSE, update clock configuration and UART/SPI timing assumptions.
- If any reference pin is hard-wired to another board function, change both firmware macros and documentation.
- Never feed 5 V into ADC pins. Some digital pins are 5 V tolerant, but ADC mode is not.
