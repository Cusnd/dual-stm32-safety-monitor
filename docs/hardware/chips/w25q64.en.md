# W25Q64 SPI NOR Flash

[Hardware index](../index.en.md) | [中文](w25q64.zh-CN.md)

## Role

W25Q64 is the optional 64 Mbit external flash on Board B. The firmware uses it as an 8 MB circular history log.

## Pins

| Pin | Function | Reference connection |
|---|---|---|
| `CS#` | Chip select, active-low | `PB12 / SPI2_NSS as GPIO` |
| `CLK` | SPI clock | `PB13 / SPI2_SCK` |
| `DO / IO1` | Data out / MISO | `PB14 / SPI2_MISO` |
| `DI / IO0` | Data in / MOSI | `PB15 / SPI2_MOSI` |
| `WP# / IO2` | Write protect / quad IO | Pulled high on most modules |
| `HOLD# / RESET# / IO3` | Hold/reset / quad IO | Pulled high on most modules |
| `VCC` | Power | 3.3 V only |
| `GND` | Ground | Common ground |

## Electrical Capability And Interface

- 64 Mbit = 8 MB.
- 256-byte page program, 4 KB sector erase.
- Standard SPI commands used here: JEDEC ID `0x9F`, read `0x03`, status `0x05`, write enable `0x06`, page program `0x02`, sector erase `0x20`.

## Generic Reference Circuit

```text
3V3 -> VCC, WP#, HOLD# through pull-ups
GND -> GND
PB12 -> CS#
PB13 -> CLK
PB14 <- DO
PB15 -> DI
```

## Firmware Mapping

- `Flash_Init_Custom()` reads JEDEC ID and loads cursor metadata.
- Sector 0 stores metadata entries.
- Logging starts at address `0x001000`; each record is 32 bytes.
- The log wraps at `0x800000`.

## Fault Symptoms

- No JEDEC ID: check 3.3 V power, CS/SCK/MISO/MOSI order, and common ground.
- Records stop updating: check sector erase timing and write-protect wiring.
