# W25Q64 SPI NOR Flash

[硬件索引](../index.zh-CN.md) | [English](w25q64.en.md)

## 项目角色

W25Q64 是板 B 可选外置 64 Mbit Flash。固件把它作为 8 MB 环形历史日志。

## 引脚

| 引脚 | 功能 | 参考连接 |
|---|---|---|
| `CS#` | 片选，低电平有效 | `PB12 / SPI2_NSS 按 GPIO` |
| `CLK` | SPI 时钟 | `PB13 / SPI2_SCK` |
| `DO / IO1` | 数据输出 / MISO | `PB14 / SPI2_MISO` |
| `DI / IO0` | 数据输入 / MOSI | `PB15 / SPI2_MOSI` |
| `WP# / IO2` | 写保护 / Quad IO | 多数模块上拉 |
| `HOLD# / RESET# / IO3` | Hold/复位 / Quad IO | 多数模块上拉 |
| `VCC` | 电源 | 只能接 3.3 V |
| `GND` | 地 | 共地 |

## 电气能力与接口

- 64 Mbit = 8 MB。
- 256 字节页写，4 KB 扇区擦除。
- 本项目使用标准 SPI 指令：JEDEC ID `0x9F`、读 `0x03`、读状态 `0x05`、写使能 `0x06`、页写 `0x02`、扇区擦除 `0x20`。

## 通用参考电路

```text
3V3 -> VCC，WP# 和 HOLD# 上拉
GND -> GND
PB12 -> CS#
PB13 -> CLK
PB14 <- DO
PB15 -> DI
```

## 固件映射

- `W25q64FlashLogger::init()` 读取 JEDEC ID 并加载游标元数据。
- `W25q64FlashLogger::process()` 以非阻塞方式推进擦除/写入任务，不阻塞 MONITOR 主循环。
- sector 0 保存 metadata。
- 日志从地址 `0x001000` 开始，每条记录 32 字节。
- 到 `0x800000` 后回绕。

## 故障现象

- 读不到 JEDEC ID：检查 3.3 V 供电、CS/SCK/MISO/MOSI 顺序和共地。
- 记录不再增长：检查扇区擦除时序和写保护引脚。
