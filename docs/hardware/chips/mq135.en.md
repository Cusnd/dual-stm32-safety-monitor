# MQ135 Gas Sensor Element

[Hardware index](../index.en.md) | [Chinese](mq135.zh-CN.md)

## Role

MQ135 is used as an air-quality trend sensor. The project reads the module AO voltage as a raw 12-bit ADC value and does not convert it to ppm.

## Element Pins

Bare MQ sensors commonly expose duplicated heater and sensing pins.

| Pin group | Function |
|---|---|
| `H/H` | Heater coil |
| `A/A` | One side of the sensing resistor |
| `B/B` | Other side of the sensing resistor |

Module boards usually expose `VCC`, `GND`, `AO`, and `DO` instead of the bare element pins.

## Electrical Capability And Interface

- Sensitive material is a heated metal-oxide gas sensor.
- Requires warm-up and calibration for quantitative measurements.
- Output is strongly affected by humidity, temperature, airflow, and load resistor.

## Generic Reference Circuit

```text
VCC -> heater and sensing divider
Rsensor + RL -> AO voltage divider
AO -> STM32 ADC input through protection/filtering if needed
AO -> LM393 threshold comparator -> optional DO
```

## Firmware Mapping

- Reference module AO connects to Board A `PA4 / ADC1_CH4`.
- Firmware applies a light integer moving average.
- Warning threshold is the active MQ135 five-level setting and is based on raw ADC value.
- Default monitor level `3/5` uses warning `2200`; `PB0` selects MQ135 and `PB1` cycles the level.

## Calibration Notes

- Let the heater stabilize before judging readings.
- Use site-specific baseline and alarm thresholds.
- Keep AO within the STM32 ADC range.
