# 10K NTC Thermistor, B=3950

[Hardware index](../index.en.md) | [Chinese](10k-ntc-b3950.zh-CN.md)

## Role

The thermistor provides an analog temperature trend on Board A. The firmware converts ADC counts to 0.1 deg C by lookup/interpolation instead of runtime floating point.

## Element Pins

| Pin | Function |
|---|---|
| Lead 1 | Resistor terminal |
| Lead 2 | Resistor terminal |

NTC thermistors are not polarized.

## Electrical Capability And Interface

- Nominal resistance: 10 kOhm at 25 deg C.
- B value: 3950 K in the reference conversion table.
- Resistance decreases as temperature rises.

## Generic Reference Circuit

```text
3V3 -> fixed resistor -> AO -> NTC -> GND
or
3V3 -> NTC -> AO -> fixed resistor -> GND
```

The firmware table must match the divider orientation. The current lookup assumes the module AO trend used by the reference thermistor module.

## Firmware Mapping

- Board A reads AO on `PA7 / ADC1_CH7`.
- `Thermistor_AdcToC10()` returns temperature in 0.1 deg C.
- Thermistor ADC fault sets `status bit3`.

## Calibration

- Verify the ADC direction by warming the probe.
- Compare with a known thermometer at two temperatures and adjust the lookup table if needed.
