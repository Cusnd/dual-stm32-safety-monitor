# LM393 Comparator

[Hardware index](../index.en.md) | [中文](lm393.zh-CN.md)

## Role

LM393 is the common dual comparator used on gas, flame, rain, and thermistor modules to convert an analog threshold into a digital `DO` signal.

## DIP/SOIC-8 Pinout

| Pin | Name | Function |
|---|---|---|
| 1 | `OUT1` | Comparator 1 open-collector output |
| 2 | `IN1-` | Comparator 1 inverting input |
| 3 | `IN1+` | Comparator 1 non-inverting input |
| 4 | `GND` | Ground |
| 5 | `IN2+` | Comparator 2 non-inverting input |
| 6 | `IN2-` | Comparator 2 inverting input |
| 7 | `OUT2` | Comparator 2 open-collector output |
| 8 | `VCC` | Supply |

## Electrical Notes

- Output is open collector and needs a pull-up.
- Many modules add a potentiometer to set the threshold.
- Output polarity depends on which input receives the sensor voltage.

## Comparator Interface

- Inputs compare an analog sensor node against a potentiometer threshold.
- The digital output is suitable for GPIO after pull-up; it is not a bus protocol and has no clock.
- Reference firmware treats flame `DO` and thermistor `DO` as active-low trigger signals.

## Generic Reference Circuit

```text
Sensor AO -> IN+
Potentiometer threshold -> IN-
OUT -> pull-up -> module DO
DO -> STM32 GPIO input
```

## Project Use

- Thermistor DO is used on Board A `PB9`.
- Flame DO is used on Board A `PB13`.
- MQ and rain comparator outputs are not required by the reference firmware unless documented by the specific module.

## Debugging

- If DO floats, check the pull-up.
- If DO polarity is unexpected, compare the module schematic or test both dry/triggered states with a multimeter.
