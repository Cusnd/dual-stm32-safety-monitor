# SSD1306 OLED Controller

[Hardware index](../index.en.md) | [Chinese](ssd1306.zh-CN.md)

## Role

SSD1306 drives the 128x64 monochrome OLED module on Board B. The reference firmware uses I2C-style bit-banged writes.

## Relevant Controller Signals

| Signal | Function | Module-level note |
|---|---|---|
| `VDD`, `VSS` | Logic supply and ground | Usually hidden on the module |
| `VCC` | OLED panel drive supply | Module may generate internally |
| `SCL/D0` | Serial clock | Module exposes as `SCL` |
| `SDA/D1` | Serial data | Module exposes as `SDA` |
| `RES#` | Reset | Often tied to module RC/reset circuit |
| `SA0/D/C#` | I2C address select or data/command | Often fixed on I2C modules |
| `SEGx/COMx` | OLED segment/common drivers | Routed inside the panel |

## Electrical Capability And Interface

- 128x64 display RAM is common for 0.96-inch modules.
- Supports I2C and SPI/parallel variants depending on module strapping.
- Typical I2C 7-bit address is `0x3C`.

## Generic Reference Circuit

```text
3V3 -> OLED VCC
GND -> OLED GND
PB6 open-drain -> SCL with pull-up
PB7 open-drain -> SDA with pull-up
```

## Firmware Mapping

- `OLED_Init_Custom()` sends the SSD1306 initialization sequence.
- `OLED_PrintLine()` writes 5x7 text into 128-pixel pages.
- No ACK error handling is implemented; an unplugged module appears as a blank display.

## Porting Notes

- If the module address is `0x3D`, update the OLED address constant.
- If the module is SPI-only, this firmware driver is not compatible without a new transport layer.
