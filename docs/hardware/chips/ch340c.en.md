# CH340C USB-UART

[Hardware index](../index.en.md) | [中文](ch340c.zh-CN.md)

## Role

CH340C is the common USB-to-UART bridge used by many STM32F103 reference boards. In this project it carries USART1 debug logs and JSON Lines between Board B and the browser dashboard.

## Pins And Signals

| CH340C signal | Direction | Typical connection |
|---|---|---|
| `UD+`, `UD-` | USB | USB connector D+/D- with ESD protection if available |
| `TXD` | Output | MCU `PA10 / USART1_RX` |
| `RXD` | Input | MCU `PA9 / USART1_TX` |
| `VCC` | Power | 5 V or 3.3 V per board design |
| `V3` | Regulator node | Follow datasheet reference circuit |
| `GND` | Power | Common ground |
| `DTR`, `RTS` | Output | Optional boot/reset automation |

## Electrical Capability And Interface

- Full-speed USB device to UART bridge.
- CH340C integrates the clock source, unlike CH340G-style crystal designs.
- UART level follows the board supply domain. Confirm it is compatible with STM32 3.3 V IO.

## Generic Reference Circuit

```text
USB D+/- -> CH340C UD+/UD-
CH340C TXD -> STM32 USART1_RX
CH340C RXD <- STM32 USART1_TX
VCC/GND -> board power and ground
DTR/RTS -> optional BOOT0/NRST circuit, not required by this firmware
```

## Firmware Mapping

- `hal::initDebugUsart1()` configures `PA9/PA10` at `115200 8N1`.
- `printf()` and Board B JSON Lines use this channel.

## Debugging

- If no serial port appears, check driver installation, USB cable data support, and CH340C power.
- If logs are garbage, check baud rate and HSE/system-clock correctness.
- If flashing through UART bootloader is added later, document the DTR/RTS/BOOT0 reset circuit explicitly.
