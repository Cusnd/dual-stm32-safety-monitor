# WS2813E Addressable RGB LED

[Hardware index](../index.en.md) | [中文](ws2813e.zh-CN.md)

## Role

WS2813E is the external high-visibility RGB status LED on Board B. The reference firmware drives one LED by TIM3 PWM plus DMA.

## Signals

WS2813E package/module naming varies by supplier. The reference design requires these signals.

| Signal | Function | Reference connection |
|---|---|---|
| `VDD/VCC` | LED supply | 5 V |
| `GND/VSS` | Ground | Common ground with Board B |
| `DIN` | Data input | `PA6 / TIM3_CH1` through level shifter if possible |
| `DOUT` | Data output | Next LED data input, unused for one LED |
| Backup input/output pins | Redundant data path on WS2813 variants | Follow the exact module datasheet |

## Electrical Capability And Interface

- Single-wire self-clocked RGB protocol around 800 kHz.
- Color byte order is GRB in the reference firmware.
- LED power is 5 V; MCU data is 3.3 V.

## Generic Reference Circuit

```text
5V -> VDD
GND -> GND and Board B GND
PA6/TIM3_CH1 -> level shifter -> DIN
DOUT -> next LED DIN, if a strip is used
```

## Firmware Mapping

- `WS2813_LED_COUNT` defaults to `1`.
- `WS2813_FillBuffer()` emits GRB order.
- `Monitor_UpdateAlarm()` maps normal/warn/danger/node-lost to green/amber/red/blue.

## Debugging

- If colors are swapped, verify GRB order and module type.
- If flicker occurs, shorten DIN wiring, improve ground, and add level shifting.
- If multiple LEDs are used, update `WS2813_LED_COUNT` and power budget.
