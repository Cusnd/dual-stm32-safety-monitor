# WS2813E Addressable RGB LED (Legacy Reference)

[Hardware index](../index.en.md) | [Chinese](ws2813e.zh-CN.md)

## Current Status

This page is kept as a hardware reference for older demos and possible future expansion. The current CMake build does not compile a WS2813 driver, and the MONITOR firmware does not drive `PA6/TIM3_CH1`.

## Signals

WS2813E package/module naming varies by supplier. A typical module exposes these signals.

| Signal | Function | Legacy reference connection |
|---|---|---|
| `VDD/VCC` | LED supply | 5 V |
| `GND/VSS` | Ground | Common ground with Board B |
| `DIN` | Data input | `PA6 / TIM3_CH1` through level shifter if firmware support is restored |
| `DOUT` | Data output | Next LED data input, unused for one LED |
| Backup input/output pins | Redundant data path on WS2813 variants | Follow the exact module datasheet |

## Electrical Notes

- Single-wire self-clocked RGB protocol around 800 kHz.
- Many implementations use GRB byte order.
- LED power is 5 V while STM32 data is 3.3 V, so a level shifter is recommended.
- Size the 5 V rail for the LED count and brightness.

## Re-Enabling Checklist

1. Restore or reimplement a WS2813 driver in `App/Drivers/`.
2. Add the driver source to `APP_MONITOR_SOURCES` in `CMakeLists.txt`.
3. Resolve the `PA6` conflict with the SENSOR rain input by keeping role-specific mapping explicit.
4. Update `WIRING.md`, README, module reference, JSON schema, and tests if the feature becomes active again.
