# CH340C USB 转串口

[硬件索引](../index.zh-CN.md) | [English](ch340c.en.md)

## 项目角色

CH340C 是常见 USB 转 UART 芯片。本项目用它承载 USART1 调试日志和板 B 输出给浏览器看板的 JSON Lines。

## 引脚与信号

| CH340C 信号 | 方向 | 典型连接 |
|---|---|---|
| `UD+`、`UD-` | USB | 接 USB 口 D+/D-，可加 ESD 防护 |
| `TXD` | 输出 | MCU `PA10 / USART1_RX` |
| `RXD` | 输入 | MCU `PA9 / USART1_TX` |
| `VCC` | 电源 | 按板卡设计接 5 V 或 3.3 V |
| `V3` | 稳压节点 | 按 datasheet 参考电路处理 |
| `GND` | 电源 | 共地 |
| `DTR`、`RTS` | 输出 | 可选自动复位/BOOT 控制 |

## 电气能力与接口

- USB 全速设备到 UART 桥接。
- CH340C 内置时钟源，不像 CH340G 方案必须外接晶振。
- UART 电平跟随板卡供电域，移植时确认与 STM32 3.3 V IO 兼容。

## 通用参考电路

```text
USB D+/- -> CH340C UD+/UD-
CH340C TXD -> STM32 USART1_RX
CH340C RXD <- STM32 USART1_TX
VCC/GND -> 板卡电源和地
DTR/RTS -> 可选 BOOT0/NRST 电路，本固件不依赖
```

## 固件映射

- `Debug_USART1_Init()` 把 `PA9/PA10` 配为 `115200 8N1`。
- `printf()` 和板 B JSON Lines 都通过该通道输出。

## 调试要点

- 电脑没有串口时，检查驱动、USB 线是否支持数据、CH340C 供电。
- 日志乱码时，检查波特率以及 HSE/系统时钟是否正确。
- 如果后续增加串口 bootloader 烧录，需要单独记录 DTR/RTS/BOOT0/复位电路。
