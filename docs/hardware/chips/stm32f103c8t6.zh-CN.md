# STM32F103C8T6 MCU

[硬件索引](../index.zh-CN.md) | [English](stm32f103c8t6.en.md)

## 项目角色

STM32F103C8T6 是两块节点板的主控。板 A 负责传感器采集和 USART3 发帧；板 B 负责收帧、显示报警、W25Q64 记录和 JSON Lines 输出。

## 封装与电气能力

| 项目 | 参考值 |
|---|---|
| 内核 | ARM Cortex-M3 |
| 最高主频 | 72 MHz |
| Flash / SRAM | C8 密度为 64 KB / 20 KB |
| 参考封装 | LQFP48 |
| 供电 | 数字电源 2.0-3.6 V；ADC 参考 VDDA |
| ADC | 12 位，输入范围 0 到 VDDA |
| 调试 | SWD 使用 `PA13/PA14` |

## 参考实现使用的 LQFP48 引脚

| 引脚 | 能力 | 参考用途 | 注意事项 |
|---|---|---|---|
| `PA0` | GPIO、ADC、WKUP | 板 B K1 | 参考板接法为高电平按下 |
| `PA1/PA2/PA3` | GPIO、ADC、TIM2 | 当前应用未使用 | 旧演示曾把这里作为板载 RGB |
| `PA4` | ADC1_CH4、SPI1_NSS | 板 A MQ135 AO | 模拟输入，不能按 5 V tolerant 使用 |
| `PA5` | ADC1_CH5、SPI1_SCK | 板 A MQ2 AO | 模拟输入，不能按 5 V tolerant 使用 |
| `PA6` | ADC1_CH6、TIM3_CH1、SPI1_MISO | 板 A 雨量 SIG | 当前 MONITOR 镜像不在此脚驱动 WS2813 |
| `PA7` | ADC1_CH7、SPI1_MOSI | 板 A 热敏 AO | 模拟输入 |
| `PA9/PA10` | USART1_TX/RX | 调试日志和 JSON 串口 | 目标板有 USB 转串口时可直连使用 |
| `PA11/PA12` | USB DM/DP | 保留 | 若目标板接了 USB，不建议复用 |
| `PA13/PA14` | SWDIO/SWCLK | 下载调试 | 开发阶段必须保留 |
| `PB0/PB1` | GPIO、ADC、TIM3 | 板 B 外接阈值按键 | 内部上拉，按下接 GND 为低电平 |
| `PB6/PB7` | GPIO、I2C1 复用 | 板 B OLED 软件 I2C | 固件按开漏 GPIO 使用 |
| `PB8` | GPIO、TIM4_CH3 | 板 B 蜂鸣器 | 推挽输出 |
| `PB9` | GPIO、TIM4_CH4 | 板 A 热敏 DO | 上拉输入，低电平高温触发 |
| `PB10/PB11` | USART3_TX/RX | 双板通信 | TX/RX 交叉并共地 |
| `PB12` | SPI2_NSS、GPIO | 板 A DHT11；板 B W25Q64 CS | 分角色复用 |
| `PB13` | SPI2_SCK、GPIO | 板 A 火焰 DO；板 B W25Q64 SCK | 数字输入/输出 |
| `PB14` | SPI2_MISO | 板 B W25Q64 MISO | SPI2 输入 |
| `PB15` | SPI2_MOSI | 板 B W25Q64 MOSI | SPI2 输出 |
| `PC13` | GPIO | 板 B K2 | 参考板接法为高电平按下 |

## 外设接口与时序

- USART1 与 USART3 均使用 `115200 8N1`；USART3 是双板二进制帧链路。
- 板 A ADC 通道为 `ADC1_CH4/5/6/7`；所有模拟输入都必须保持在 0..VDDA。
- 板 B SPI2 通过 `PB13/PB14/PB15` 的标准单线 SPI 访问 W25Q64；`PB12` 按 GPIO 片选控制。
- 当前板 B 固件不使用 `PA6/TIM3_CH1`；旧 WS2813 演示曾使用该路径。
- OLED I2C 使用 `PB6/PB7` 软件开漏 GPIO，而不是硬件 I2C 外设。

## 通用参考电路

```text
3V3 -> VDD/VDDA，并在电源脚附近放置 100 nF 去耦
GND -> VSS/VSSA
8 MHz HSE -> OSC_IN/OSC_OUT，若目标板提供外部晶振
BOOT0 -> 下拉，默认从内部 Flash 启动
NRST -> 上拉，可并联复位按键
PA13/PA14 -> SWD 下载调试接口
```

## 固件映射

- `SystemClock_Config()` 按 8 MHz HSE 到 72 MHz SYSCLK 配置。
- `hal::initAdc1()` 和 `hal::readAdc1Channel()` 在 SENSOR 固件中采样 `PA4/PA5/PA6/PA7`。
- `hal::initNodeUsart3()` 在两种固件中使用 `PB10/PB11`。
- `Buttons::init()` 在 MONITOR 固件中把 `PB0/PB1` 配置为低有效外接阈值按键。
- `W25q64FlashLogger::init()` 只在 MONITOR 固件中调用 `MX_SPI2_Init()`，并使用 `PB13/PB14/PB15` 上的 HAL SPI 加 `PB12` GPIO CS。

## 移植检查

- 如果目标板没有 8 MHz HSE，需要同步修改时钟、串口和 SPI 时序假设。
- 如果参考引脚被板载功能占用，需要同时修改固件宏和文档。
- 不要给 ADC 引脚输入 5 V。部分数字 IO 可以 5 V tolerant，但模拟模式不可以。
