# MQ2 气敏元件

[硬件索引](../index.zh-CN.md) | [English](mq2.en.md)

## 项目角色

MQ2 用作烟雾和可燃气体趋势传感器。项目按阈值档位把较高 ADC 原始值判为预警或危险。

## 元件引脚

| 引脚组 | 功能 |
|---|---|
| `H/H` | 加热丝 |
| `A/A` | 敏感电阻一端 |
| `B/B` | 敏感电阻另一端 |

常见模块板通常对外提供 `VCC`、`GND`、`AO`、`DO`。

## 电气能力与接口

- 对烟雾和多种可燃气体有响应。
- 需要加热供电和预热。
- 本固件不能用它识别单一气体种类。

## 通用参考电路

```text
5V 模块电源 -> 加热丝
Rsensor + RL -> AO
AO -> STM32 ADC，需分压/限幅到 <= 3.3 V
AO -> 可选比较器阈值 -> DO
```

## 固件映射

- 参考 AO 接板 A `PA5 / ADC1_CH5`。
- `evaluateAlarm()` 先按当前档位的 MQ2 危险阈值判定，再进入预警逻辑。
- 数值是 ADC 原始计数，不是气体浓度。

## 调试要点

- 数值完全不变时，检查加热电源和 AO 接线。
- ADC 饱和时，加分压或确认模块 AO 输出范围。
