# DHT11 传感芯片

[硬件索引](../index.zh-CN.md) | [English](dht11.en.md)

## 项目角色

DHT11 在板 A 提供低成本温湿度数字读数。项目按安全间隔读取，并通过 `STATUS_DHT_ERROR` 上报失败。

## 引脚

| 引脚 | 功能 | 参考连接 |
|---|---|---|
| `VDD` | 电源 | 参考模块接 3.3 V |
| `DATA` | 双向单总线信号 | 板 A `PB12` |
| `NC` | 不连接 | 悬空 |
| `GND` | 地 | 共地 |

## 电气能力与接口

- 单总线风格数字协议。
- 40 bit 数据：湿度、温度和校验字节。
- 采样速度较低；固件保证两次读取至少间隔 2100 ms。

## 通用参考电路

```text
3V3 -> VDD
PB12 <-> DATA，并通过上拉电阻接 3V3
GND -> GND
```

## 固件映射

- `DHT11_Read()` 发送开始脉冲、切换 GPIO 输入、读取 40 bit 并校验。
- `DHT11_PERIOD_MS` 控制安全采样间隔。
- 失败时设置 `status bit0`。

## 故障现象

- `status bit0` 长期存在：检查上拉、电源线序和采样间隔。
- 读数一直为 0 或不刷新：检查模块供电和 DATA 方向切换。
