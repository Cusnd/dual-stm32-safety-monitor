# WS2813E RGB 模块

[硬件索引](../index.zh-CN.md) | [English](ws2813e-rgb-module.en.md) | [WS2813E 芯片](../chips/ws2813e.zh-CN.md)

## 项目角色

板 B 使用外置 WS2813E RGB 灯珠或灯带作为高可视报警指示。

## 模块引脚

| 模块引脚 | 电气角色 | 参考连接 |
|---|---|---|
| `VCC` | 灯珠电源 | 5 V |
| `GND` | 地 | 与板 B 共地 |
| `DIN` | 数据输入 | `PA6 / TIM3_CH1` |
| `DOUT` | 数据输出 | 下一颗灯，可选 |

## 电气与接口要点

- 灯珠电源为 5 V，电流可能远高于 GPIO 能力；需要按灯珠数量和亮度预算 5 V 电源。
- 数据协议约为 800 kHz 单线码流；固件用 TIM3 PWM + DMA 按 GRB 字节顺序发送。
- 建议在 `DIN` 前加入 3.3 V 到 5 V 电平转换，长线或灯带场景尤其需要。

## 通用参考电路

```text
5V -> VCC
GND -> GND，并与板 B 共地
PA6 -> 3.3V 到 5V 电平转换 -> DIN
DOUT -> 下一颗灯 DIN
```

## 固件映射

- `RGB_LED_COUNT` 概念在固件中对应 `WS2813_LED_COUNT`。
- 默认数量为 1。
- 颜色顺序为 GRB。
- JSON 字段：`externalRgb`。

## 测试要点

- 正常 = 绿，预警 = 琥珀，危险 = 红，节点离线 = 蓝。
- 第一颗亮但后续不亮时，检查数量、电源注入和 DOUT 串接。
