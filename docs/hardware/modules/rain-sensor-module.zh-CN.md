# 雨量模块

[硬件索引](../index.zh-CN.md) | [English](rain-sensor-module.en.md) | [LM393](../chips/lm393.zh-CN.md)

## 项目角色

板 A 使用雨量模块 `SIG` 模拟输出判断干湿趋势。雨量湿态属于预警级事件。

## 模块引脚

| 模块引脚 | 电气角色 | 参考连接 |
|---|---|---|
| `VCC` | 模块供电 | 3.3 V |
| `GND` | 地 | 共地 |
| `SIG` / `AO` | 雨滴板模拟信号 | `PA6 / ADC1_CH6` |
| `DO` | 可选比较器输出 | 本固件不使用 |

## 电气与接口要点

- 参考设计用 3.3 V 给模块供电，因此 `SIG/AO` 默认落在 STM32 ADC 量程内。
- 干/湿方向和阈值会随模块电阻网络变化，需要用实测干燥值和湿态值标定。
- 可选 `DO` 是比较器阈值信号，本固件有意不使用它。

## 通用参考电路

```text
雨滴板电阻 -> 模拟分压 -> SIG
SIG -> PA6 ADC
SIG + 电位器 -> 可选 LM393 DO
```

## 固件映射

- `ADC1_ReadChannel(6)` 采样雨量。
- 默认湿态阈值从原始值 `1400` 起步。
- JSON 字段：`rainRaw`、`rainWet`；状态位：`bit2`。

## 标定

- 在实际模块上记录干燥、轻微打湿、明显湿态 ADC。
- 把湿态阈值放在干燥值和湿态值之间。
- 腐蚀和残留会改变读数，测试后清洁雨滴板。
