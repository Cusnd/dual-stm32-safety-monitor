# MQ135 模块

[硬件索引](../index.zh-CN.md) | [English](mq135-module.en.md) | [MQ135 元件](../chips/mq135.zh-CN.md) | [LM393](../chips/lm393.zh-CN.md)

## 项目角色

板 A 使用 MQ135 AO 作为空气质量趋势原始输入。参考固件不使用模块比较器 DO。

## 模块引脚

| 模块引脚 | 电气角色 | 参考连接 |
|---|---|---|
| `VCC` | 加热/模块供电 | 5 V 或模块额定电源 |
| `GND` | 地 | 共地 |
| `AO` | 模拟分压输出 | `PA4 / ADC1_CH4` |
| `DO` | 比较器输出 | 不接 |

## 电气与接口要点

- 加热丝侧可能需要 5 V 且电流较大，应使用能承载模块电流的电源轨。
- 即使模块用 5 V 供电，送入 STM32 ADC 的 `AO` 也必须限制在 0..3.3 V。
- `AO` 是响应较慢的模拟趋势信号；`DO` 只是电位器/比较器阈值输出，参考固件不使用。

## 通用参考电路

```text
气敏元件 + 负载电阻 -> AO
AO -> PA4 ADC，保护到 0..3.3 V
AO + 电位器 -> LM393 -> DO
```

## 固件映射

- `hal::readAdc1Channel(4)` 采样 MQ135。
- 板 B 使用 5 档可调 ADC 原始值空气预警阈值；默认显示为 `3/5`，数值为 `2200`。
- PB0 可在 MONITOR 阈值页选择 MQ135，PB1 让 `thresholdAirLevel` 在 `0..4` 间循环。
- JSON 字段：`mq135Raw`、`thresholdAirLevel`、`thresholdAirWarn`。

## 测试与标定

- 预热后再判断数值。
- 记录洁净空气基线和安全刺激响应。
- 如果 AO 可能超过 3.3 V，进入 `PA4` 前必须分压或限幅。
