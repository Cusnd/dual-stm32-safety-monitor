# DHT11 模块

[硬件索引](../index.zh-CN.md) | [English](dht11-module.en.md) | [DHT11 芯片](../chips/dht11.zh-CN.md)

## 项目角色

板 A 用该模块采集环境温湿度。它是低速数字传感器，所以固件读取频率低于 1 秒发帧周期。

## 模块引脚

| 模块引脚 | 电气角色 | 参考 STM32 引脚 |
|---|---|---|
| `VCC` | 本设计接 3.3 V | `3V3` |
| `DATA` | 双向单总线数据 | `PB12` |
| `NC` | 不连接 | 悬空 |
| `GND` | 地 | `GND` |

## 电气与接口要点

- `DATA` 是双向单总线信号，需要上拉到模块供电电压。
- 主机起始脉冲后，传感器返回 40 bit 湿度、温度和校验数据。
- 采样间隔必须较慢；参考固件用 `DHT11_PERIOD_MS` 限制两次读取间隔。

## 通用参考电路

```text
3V3 -> VCC
PB12 <-> DATA
DATA -> 上拉电阻 -> 3V3
GND -> GND
```

## 固件映射

- `DHT11_PORT/PIN` = `GPIOB/PB12`。
- `DHT11_Read()` 校验 40 bit 数据。
- `status bit0` 表示读取失败。

## 测试与故障

- 通过标准：温湿度约每 3 秒更新，`status bit0` 不长期置位。
- 失败时检查上拉、电缆长度、DATA 线序和共地。
