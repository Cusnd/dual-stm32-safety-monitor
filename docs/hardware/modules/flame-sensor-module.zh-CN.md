# 火焰模块

[硬件索引](../index.zh-CN.md) | [English](flame-sensor-module.en.md) | [LM393](../chips/lm393.zh-CN.md)

## 项目角色

板 A 使用数字 DO 输出检测类似火焰的红外强度。火焰触发属于危险级事件。

## 模块引脚

| 模块引脚 | 电气角色 | 参考连接 |
|---|---|---|
| `VCC` | 模块供电 | 3.3 V 或模块额定电源 |
| `GND` | 地 | 共地 |
| `DO` | 比较器输出 | `PB13`，低电平触发 |
| `AO` | 可选模拟输出 | 不接 |

## 电气与接口要点

- 参考固件只使用 `DO`；LM393 类输出按上拉输入读取，低电平表示触发。
- `AO` 因模块版本不同而不同，本引脚图不使用；若改接 ADC，必须先确认范围在 0..3.3 V 内。
- 火焰模块适合演示和趋势监测，不是经过认证的消防安全传感器。

## 通用参考电路

```text
红外光敏二极管/三极管 -> 模拟节点
模拟节点 + 电位器 -> LM393 -> DO
DO -> PB13 上拉输入
```

## 固件映射

- `PB13` 为 `GPIO_PIN_RESET` 时表示 `flame=1`。
- 火焰危险优先级高于预警状态。
- JSON 字段：`flame`。

## 测试要点

- 只用安全光源/红外方式测试，避免明火靠近电路。
- 演示前调整模块阈值，避免太阳光或遥控器误触发。
